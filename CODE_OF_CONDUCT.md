# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and critique work
rather than people. Harassment, personal attacks, and discriminatory language
are not tolerated in issues, pull requests, discussions, or any other project
space.

## Reporting

Report unacceptable behavior to the maintainer through a
[private security advisory](https://github.com/who-is-michael-mercer/caveman/security/advisories/new)
(it reaches the maintainer privately even though it is not a security issue),
or by contacting the maintainer through their GitHub profile. Reports are
handled confidentially.

Maintainers may remove, edit, or reject comments, commits, code, issues, and
other contributions that violate this code, and may temporarily or permanently
ban contributors for behavior they deem harmful, following the enforcement
guidelines of the Contributor Covenant.
